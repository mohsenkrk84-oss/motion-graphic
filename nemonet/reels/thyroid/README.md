# ریلز کم‌کاری تیروئید — نمونت

ریلز ۲۵ ثانیه‌ای (۱۰۸۰×۱۹۲۰، ۳۰ فریم) در سبک آدمک مدادی روی کاغذ خاکستری (مرجع: `decipline.mp4`).
قلاب: «همه‌چی رو امتحان کردی و باز هم نشد؟» — «تو» به وزنه‌ی «تیروئید کم‌کار» زنجیر شده؛ آزمایش TSH + T4 نمونت زنجیر را باز می‌کند.

- `nemonet_thyroid_reel.mp4` — خروجی نهایی (صدای Setareh از ElevenLabs، با ۴٪ سرعت بیشتر)
- `cover_thyroid.png` — کاور ریلز (جدا آپلود می‌شود)
- `source/` — آدمک‌ها (`lib.js`)، صحنه‌ها به‌صورت تابعی از زمان (`scenes.js`)، رندر با Playwright، صدا (`audio.py`)

برچسب‌های دست‌نویس با فونت Marhey (OFL). این فونت «ی» فارسیِ وسط کلمه را بی‌نقطه می‌کشد؛ `handFix` در `lib.js` آن را با «ي» عربی جایگزین می‌کند.
