# ریل نمونه‌گیری خانم‌ها و آقایون – نمونِت

**فایل نهایی:** `nemonet_men-vs-women_reel.mp4` (حدود ۳۶ ثانیه، 1080×1920، 30fps)

سبک: کمیک دست‌کشیده با خط نازک و رنگ پاستلی؛ تیتر بالای صفحه («نمونه‌گیری از خانم‌ها» / «نمونه‌گیری از آقایون») و یک خط زیرنویس.

## صحنه‌ها
1. `1-1`: سرنگ و ۸ لوله – «سلام» / «باید ۸ تا لوله خون بگیرم»
2. `2-1`، `2-2`: «رگت هم خیلی باریکه...» / «پس سوزن... یه کم درد داره»
3. `3-1`/`3-2` (لب‌خوانی)، `3-3`: «اشکال نداره» / «درک می‌کنم»
4. `4-1`، `4-2`: نمونه‌گیر پاورچین و ژست حمله – «آروم باش...»
5. `5-1`: دندون‌قروچه (با نوار کرم پشت تیتر)
6. `2-3`، `2-4`/`2-5`: «تموم شد!» / «عه، زدی؟» / «اصلاً حس نکردم!»
7. `6-1`/`6-2`: «آره دیگه...» / «دستت خیلی سبکه»
8. `7-1` → `7-2`: «مرسییی!»
9. `8-1`، `8-2`، `8-3`: «فقط یه پنبه‌ست...» / «یه ثانیه‌ست» / «آی» (موزیک قطع می‌شود)
10. `9-1`/`9-2` (جابه‌جایی سریع)، `9-3` (کوچک‌شده تا به متن نخورد)، `9-4`: جیغ، پرتاب و برخورد با دیوار

## صدا
- `v1.mp3` تا `v14.mp3`: دیالوگ‌ها (ElevenLabs v4)
- `audio/s1.wav` تا `audio/s10.wav` و `audio/music.wav`: افکت‌ها و موزیک، کاملاً با کد ساخته شده (`source/sfx.py`) – بدون مشکل کپی‌رایت

## ساخت دوباره
```
python3 -I source/sfx.py audio                       # افکت‌ها و موزیک
python3 -I source/build.py out.mp4                   # کل ویدئو
python3 -I source/build.py p.mp4 --preview 28 36     # فقط یک بازه
python3 -I source/build.py x.mp4 --sheet sheet.jpg   # کانتکت‌شیت فریم‌ها
```
