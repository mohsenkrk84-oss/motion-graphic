# ریل قند خون (گشنگی بعد از غذا) – نمونِت

**فایل نهایی:** `nemonet_blood-sugar_reel.mp4` (۵۸ ثانیه، 1080×1920، 30fps)

## صحنه‌ها
1. داخل بدن رضا: معده در حال ترکیدن، دماسنج قند خون تا قرمز بالا می‌ره، کلیدهای انسولین می‌دوند بیرون (`1-*.jpg`)
2. دو ساعت بعد: معده خالیه، لوزالمعده با چای هنوز انسولین می‌فرسته، قند سقوط می‌کنه (`2-*.jpg`)
3. قاب دوتکه، مغز و معده: «پس چرا هوس شیرینی کردم؟» (`3-*.jpg`)
4. خونه: رضا و مینا، شکم رضا قار و قور می‌کنه، کارت پایانی علمی (`4-*.jpg`)

دماسنج قند خون، برچسب‌ها («معده»، «لوزالمعده»، «انسولین»)، عنوان‌ها و زیرنویس‌ها با کد ساخته می‌شن.

## صدا
- `audio/v1.mp3` تا `v9.mp3`: دیالوگ‌ها (ElevenLabs v4)
- `audio/s1.mp3` تا `s10.mp3`: افکت‌ها، `s11-1-2.mp3`: موزیک

## ساخت دوباره
```
python3 -I source/build.py out.mp4
python3 -I source/build.py preview.mp4 --preview 12 28   # فقط یک بازه
```
