# ریل موی زیرپوستی – نمونِت

**فایل نهایی:** `nemonet_ingrown-hair_reel.mp4` (۷۲ ثانیه، 1080×1920، 30fps)

## صحنه‌ها
1. داخل پوست: دعوای «تیغ» و «مو» و تراشیدن (`1-*.jpg`)
2. چند هفته بعد: تراشیدن خلاف جهت و تهدید مو (`2-*.jpg`)
3. انتقام: موی زیرپوستی و جوش التهابی (`3-*.jpg`)
4. مطب دکتر، با کات به «خلاف جهت رشد مو» (2-4)، «موی زیرپوستی» (3-1) و «هم‌جهت رشد مو» (5-1) (`4-*.jpg`)
5. آشتی تیغ و مو (`5-*.jpg`)

حالت‌های دهان بسته‌ی `1-3`، `2-3` و `2-6` داخل `build.py` از تصویر هم‌تراز دیگر ساخته می‌شوند.

## صدا
- `v1.mp3` تا `v12.mp3`: دیالوگ‌ها (ElevenLabs v4)
- `s1.mp3` تا `s7.mp3`: افکت‌ها، `s8.mp3`: موزیک (۶۷ ثانیه، با کراس‌فید ادامه داده می‌شود)

## ساخت دوباره
```
python3 -I source/build.py out.mp4
python3 -I source/build.py preview.mp4 --preview 40 50   # فقط یک بازه
```
