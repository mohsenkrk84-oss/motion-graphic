# ریلز «نصف روزت یا ۱۰ دقیقه؟» — نمونت

ریلز تبلیغی ۲۹.۴ ثانیه‌ای (۱۰۸۰×۱۹۲۰، ۳۰ فریم) در سبک تصویرسازی برداری تخت با بافت مدادشمعی.
صدای گوینده: ElevenLabs (Setareh). زیرنویس کلمه‌به‌کلمه با زمان‌بندی دقیق کلمات (ElevenLabs Scribe).
موسیقی و افکت‌ها با کد ساخته شده‌اند. فونت: ایران‌یکان.

- `nemonet_reel_A.mp4` — خروجی نهایی
- `storyboard/` — استوری‌بورد
- `source/` — صحنه‌ها و تایم‌لاین GSAP (`scenes.js`)، رندر فریم‌ها با Playwright (`render.py`)، صدا (`audio.py`)

ساخت دوباره: فونت‌ها و `app-icon-tide.png` از ریشه‌ی مخزن کنار `anim.html` کپی شوند، بعد
`python3 render.py frames 0 882`، `python3 audio.py` و ترکیب با ffmpeg.
