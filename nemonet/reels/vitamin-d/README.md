# ریلز ویتامین D — نمونت

ریلز ۲۰ ثانیه‌ای اینستاگرام (۱۰۸۰×۱۹۲۰، ۲۴ فریم) درباره‌ی کمبود ویتامین D و آزمایش در منزل نمونت.
همه‌ی فریم‌ها با کد رسم شده‌اند؛ سبک دست‌کشیده با بافت مدادی و حرکت «روی دوتایی».

- `nemonet_vitaminD_reel.mp4` — خروجی نهایی با صدای گوینده، موسیقی و افکت‌ها
- `storyboard/` — دو فریم کلیدی استوری‌بورد (قلاب و دعوت به اقدام)
- `source/` — کد ساخت ویدیو

## صحنه‌ها
1. قلاب: «همیشه خسته‌ای؟»
2. باتری ویتامین D خالی
3. نشانه‌ها: خستگی مداوم، درد استخوان و عضله، ضعف عضلانی
4. «حتی تو کشور آفتابی هم کمبودش خیلی شایعه»
5. رزرو آنلاین و آمدن نمونه‌گیر به خانه
6. دعوت به اقدام: لوگو، nemonet.ir، «همین حالا نوبت بگیر»

## ساخت دوباره
پیش‌نیاز: Python 3 با Pillow (با raqm)، numpy و scipy، ffmpeg، و فونت [Vazirmatn](https://github.com/rastikerdar/vazirmatn).
مسیر فونت، لوگو و صدای گوینده در کد به‌صورت مسیر مطلق آمده و باید با محیط شما تنظیم شود.

```
python3 vo_fit.py   # کوتاه کردن مکث‌های صدای گوینده و ساخت timing.json
python3 audio.py    # ساخت موسیقی و افکت‌ها
python3 anim.py     # رندر فریم‌ها
```

سپس فریم‌ها و صداها با ffmpeg ترکیب می‌شوند (موسیقی هنگام صحبت گوینده خودکار پایین می‌آید).

صدای گوینده با ElevenLabs (صدای Setareh) ساخته شده؛ موسیقی و افکت‌ها با کد ساخته شده‌اند.
