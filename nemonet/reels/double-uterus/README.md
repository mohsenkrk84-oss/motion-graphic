# ریل رحم دوقلو – «باردار، ولی پریود؟!» – نمونِت

**فایل نهایی:** `nemonet_double_uterus_reel.mp4` (۵۰ ثانیه، 1080×1920، 30fps)

## صحنه‌ها
1. ورود مسافر: اسپرم با کوله‌پشتی بالا میاد، رحم ۱ استقبال می‌کنه، رحم ۲ قبول نمی‌کنه (`1-*.jpg`)
2. مرخصی خیالی: جنین در رحم ۱، رحم ۲ فکر می‌کنه نُه ماه پریود تعطیله (`2-*.jpg`)
3. هورمون‌ها: حباب‌های هورمون، دیواره‌ی رحم ۲ کلفت می‌شه و می‌ریزه، مهر «پریود!» (`3-*.jpg`)
4. مطب: دکتر رحم دوقلو رو توضیح می‌ده و می‌گه هر خونریزی در بارداری رو به پزشک بگید (`4-*.jpg`)

## صدا
- `v1.mp3` تا `v10.mp3`: دیالوگ‌ها (ElevenLabs v4)
- `s1`–`s7`، `s9`: افکت‌ها، `s8.mp3`: موزیک (۷۳ ثانیه)

## هماهنگی صدا و تصویر
- زمان دقیق هر کلمه با ElevenLabs Scribe گرفته شده و در `source/words/vN.json` ذخیره شده. زیرنویس، باز و بسته شدن دهن و اتفاق‌های تصویری (کلفت شدن دیواره روی «کلفت»، ریزش و مهر روی «بریزیش») از همین زمان‌ها میان.
- مکث‌های بیشتر از ۰٫۲۶ ثانیه بین کلمه‌ها کوتاه می‌شن؛ سرعت صدا تغییر نمی‌کنه.
- برای لب‌زدن فقط ناحیه‌ی دهن از نسخه‌ی دهن‌باز روی تصویر پایه جایگذاری می‌شه (`face_swap`).

## ساخت دوباره
```
python3 -I source/build.py out.mp4
python3 -I source/build.py preview.mp4 --preview 17 32   # فقط یک بازه
python3 -I source/build.py x.mp4 --sheet sheet.jpg       # کانتکت‌شیت از فریم‌های کلیدی
```
