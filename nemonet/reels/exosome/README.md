# ریلز «ترند در برابر واقعیت (اگزوزوم‌ها)» — نمونت

ریلز ۲۳.۵ ثانیه‌ای (۱۰۸۰×۱۹۲۰، ۳۰ فریم) در سبک لاین‌آرت + پرشدگی مداد رنگی روی زمینه‌ی کرم.
مرجع‌ها: `line-art-woman-animation-pack…mp4` (رسم خط پیوسته + دایره‌های پاستلی) و تصویرسازی فلت با بافت مدادی.

- `nemonet_exosome_reel.mp4` — خروجی نهایی (صدای Setareh از ElevenLabs، موزیک ElevenLabs Music)
- `cover_exosome.png` — کاور ریلز (جدا آپلود می‌شود)
- `storyboard/frames_exosome.png` — فریم‌های نمونه از هر صحنه
- `source/` — اسکریپت‌ها

## صحنه‌ها
1. قلاب — تزریق در کلینیک: «اگزوزوم و تزریق‌های میلیونی واقعاً معجزه می‌کنن؟ یا فقط هدر دادن پوله؟»
2. آزمایشگاه: «اگه علت لک یا آکنه شما اختلال هورمونی باشه… ۱۰ جلسه اگزوزوم هم موقتیه!»
3. برگه‌ی آزمایش: «اول باید هورمون‌هات رو بررسی کنی» + برچسب‌های LH، FSH، تستوسترون، DHEA-S + کارت «آزمایش هورمونی در خانه | نمونت»
4. CTA: «کدام درمان ترند پوستی رو امتحان کردی؟ تو کامنت‌ها برام بنویس!»

## روش ساخت
تصاویر هر صحنه با Gemini ساخته شده‌اند (`nemonet/Gemini_Generated_Image_*.jpg`).
- `prep.py` — خطوط تیره را جدا می‌کند و ترتیب رسم را در طول خط (فاصله‌ی ژئودزیک) محاسبه می‌کند؛ دایره‌های پس‌زمینه و پرشدگی‌ها را جدا می‌کند → `layers/*.npz`
- `timing.py` — زمان هر جمله‌ی نریشن را از مکث‌های `vo.mp3` پیدا می‌کند → `timings.json`
- `render.py` — فریم‌ها: رسم خط، pop دایره‌ها، پرشدگی مدادی، کپشن کلمه‌به‌کلمه، برچسب‌ها، انتقال دایره‌ای
- `sfx.py` — افکت‌های صوتی (مداد، pop، whoosh، ding) از روی `events.json`

```
python3 prep.py ../../.. layers
python3 timing.py ../../../vo.mp3 timings.json
python3 render.py layers ../../.. timings.json frames
python3 sfx.py events.json sfx.wav 23.56
```
میکس نهایی با ffmpeg: نریشن ۰.۱۵ ثانیه تأخیر، موزیک با sidechain زیر صدا، loudnorm روی ‎-14 LUFS.
