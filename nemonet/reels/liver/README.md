# ریل کبد چرب – نمونِت

**فایل نهایی:** `nemonet_liver_reel.mp4` (۶۵ ثانیه، 1080×1920، 30fps)

## صحنه‌ها
1. کبد وزنه‌به‌دست → قند و نوشابه می‌رسد → کبد خسته (`1-*.jpg`، تصاویر تست در `source/test/`)
2. داخل کبد: دو کلید «انسولین» و انبارهای پر چربی (`2-*.jpg`)
3. چربی لای عضله‌ها (`3-*.jpg`)
4. مطب دکتر، چاقی از درون (`4-*.jpg`)

## صدا
- `audio/v0.mp3` تا `v10.mp3`: دیالوگ‌ها (ElevenLabs v4)
- `audio/s1.mp3` تا `s7.mp3`: افکت‌ها، `s8-1` و `s8-2`: موزیک

## ساخت دوباره
```
python3 -I source/build.py out.mp4
python3 -I source/build.py preview.mp4 --preview 13 25   # فقط یک بازه
```
