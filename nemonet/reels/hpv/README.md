# ریلز HPV — نمونت

ریلز ۲۰ ثانیه‌ای اینستاگرام (۱۰۸۰×۱۹۲۰، ۲۴ فریم) با فرمت «۳ باور غلط» درباره‌ی HPV و آزمایش HPV در منزل نمونت.
همه‌ی فریم‌ها با کد رسم شده‌اند؛ همان سبک دست‌کشیده‌ی ریلز ویتامین D، با حرکت «روی دوتایی» و لرزش خط.

- `nemonet_hpv_reel.mp4` — خروجی نهایی با صدای گوینده، موسیقی، افکت‌ها و زیرنویس
- `storyboard/` — استوری‌بورد، برگه‌ی کاراکترها و کاور (کاور جدا آپلود می‌شود)
- `source/` — کد ساخت

## صحنه‌ها
1. قلاب: «۳ تا چیزی که درباره‌ی HPV اشتباه فکر می‌کنی» (ویروس عامل زگیل تناسلی)
2. باور غلط ۱: نادره ← خیلی رایجه
3. باور غلط ۲: فقط مال خانم‌هاست ← آقایون هم می‌گیرن
4. باور غلط ۳: حتماً علامت داره ← اغلب بی‌علامته
5. غربالگری = خیال راحت (نمونه‌گیر نمونت)
6. نمونت؛ آزمایش در منزل — گوینده: «نمونت، آزمایش HPV در محیط امن خونه‌ات»

## ساخت دوباره
پیش‌نیاز: Python 3 با Pillow (raqm) و numpy، ffmpeg. فونت IRANYekan از ریشه‌ی همین ریپو خوانده می‌شود.
صداها (vo.mp3، music.mp3، pop/scribble/whoosh/doorbell/chime.mp3) با ElevenLabs ساخته شده‌اند و در پوشه‌ی `AUD` قرار می‌گیرند.

```
python3 vo_fit.py   # کوتاه کردن مکث‌های گوینده و ساخت timing.json
python3 audio.py    # میکس گوینده، موسیقی و افکت‌ها
python3 anim.py     # رندر ۲۴۰ نقاشی (۱۲ در ثانیه، پخش روی دوتایی در ۲۴fps)
```
