# ریل جوش، فشار نده! – نمونِت

**فایل نهایی:** `nemonet_pimple_reel.mp4` (۷۰ ثانیه، 1080×1920، 30fps)

## صحنه‌ها
1. جوش و انگشت: جوش انگشت رو مسخره می‌کنه و از فشارش خنده‌ش می‌گیره (`1-*.jpg`)
2. موچین: فشار، پاشیدن چرک و ظاهر شدن جوش تازه (`2-*.jpg`)
3. زیر پوست: جوش عمیق‌تر می‌شه و جای جوش می‌مونه (`3-*.jpg`)
4. مطب: دکتر توضیح می‌ده چرا نباید فشار داد، و اگه جوش‌ها زیاد و همیشگی‌ان، متخصص پوست و آزمایش (`4-*.jpg`)

## صدا
- `v1.mp3` تا `v14.mp3`: دیالوگ‌ها (ElevenLabs v4)
- `s1`–`s7`، `s9`–`s11`: افکت‌ها، `s8-1` و `s8-2`: موزیک

## نکته‌ی لب‌زدن
برای هر ژست فقط یک تصویر پایه استفاده می‌شه و موقع حرف زدن فقط ناحیه‌ی صورت از نسخه‌ی دهن‌باز روش جایگذاری می‌شه (`face_swap` در `build.py`)، تا دست‌ها و بدن نلرزن.

## ساخت دوباره
```
python3 -I source/build.py out.mp4
python3 -I source/build.py preview.mp4 --preview 8 23   # فقط یک بازه
python3 -I source/build.py x.mp4 --sheet sheet.jpg       # کانتکت‌شیت از فریم‌های کلیدی
```
